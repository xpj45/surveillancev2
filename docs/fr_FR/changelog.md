# Changelog Surveillance Equipement V2

## Version courante
- Compatibilité Jeedom 4.4+ / PHP 8, plugin renommé `surveillancev2`.
- Alarme 64 (inactivité trop longue), durée définissable par jour.
- Fréquence de vérification des alarmes commune.
- Répétition de chaque alarme au choix, période commune.
- Actions filtrées par numéro d'alarme.
- Remise à zéro périodique des temps d'activité et d'inactivité.
- Boutons Configuration et Logs, logs de debug détaillés.
- Nouvelle présentation de l'écran de configuration.
